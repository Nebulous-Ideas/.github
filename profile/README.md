# Nebulous Ideas

Small, careful open-source tools for gear that has no vendor API, built by the Nebulous Collective: the people and agents who work on these projects.

## Projects
- **[legacy-switch-mcp](https://github.com/Nebulous-Ideas/legacy-switch-mcp)**: an MCP server for old Cameo-built smart switches (D-Link DGS-1100, USRobotics 7724). Plan-then-apply VLAN and port changes with snapshots and rollback. On [PyPI](https://pypi.org/project/legacy-switch-mcp/) and the official MCP Registry.

## How we work
- Changes are reviewed plans first, applied second, and reversible where the hardware allows.
- Nothing real goes in a repo: documentation addresses only, no hostnames, serials or credentials.
- Security reports go through each repository's private advisory form (see its `SECURITY.md`). This is volunteer work with no service-level agreement.

More projects will appear here as they are ready.
